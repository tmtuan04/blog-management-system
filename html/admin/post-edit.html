Bản dịch · English

Tiêu đề cần từ 5 đến 255 ký tự.

Angular is a frontend framework built by Google. It is written in TypeScript and ships almost everything a large app needs: routing, forms, HTTP calls and testing.

Setting up

You need Node.js LTS and the Angular CLI. Install the CLI with npm install -g @angular/cli, then create a new project with ng new.

Project structure

  • src/app: components, services and routes.
  • src/assets: images, fonts and static files.
  • angular.json: build configuration.
Do not try to learn everything at once. Get one small screen working, then read on.
