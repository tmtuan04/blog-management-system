Không tìm thấy key nào

Không có key hoặc giá trị nào khớp với “dashbord”. Thử từ khóa khác, hoặc thêm key mới.

Thêm key

Chữ thường, số, dấu chấm và gạch dưới, dạng nhóm.tên. Ví dụ: menu.blog, post.read_more.
Key “menu.home” đã có. Tìm key đó trong bảng để sửa giá trị.
Không bắt buộc. Để trống thì hiện giá trị ở ngôn ngữ mặc định.

Xóa key?

footer.copyright

Giá trị của key ở mọi ngôn ngữ sẽ bị xóa. Chỗ nào trên giao diện còn dùng key này sẽ hiện tên key thay cho chữ. Không thể hoàn tác.
