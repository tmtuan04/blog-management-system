Hướng dẫn Angular

Tìm hiểu cách dựng một ứng dụng Angular từ đầu: component, service, routing và cách gọi API từ backend.

Nguyễn Văn An · Lập trình
6 phút đọc · 12/10/2026
120 lượt xem 40 bình luận

Bài viết này có ở các ngôn ngữ: Tiếng Việt · English

Angular là framework frontend do Google phát triển, đi kèm sẵn mọi thứ cần cho một ứng dụng lớn: component, dependency injection, router, form và HTTP client. Bài này đi từ lúc tạo dự án đến khi gọi được API thật từ backend NestJS.

Bạn chỉ cần biết JavaScript cơ bản và đã cài Node.js. Nếu chưa quen TypeScript, hãy đọc qua Làm quen với TypeScript trong một buổi chiều trước khi bắt đầu.

Tạo dự án

Cài Angular CLI rồi tạo dự án mới. Chọn có routing và dùng SCSS cho style:

npm install -g @angular/cli
ng new blog-frontend --routing --style=scss
cd blog-frontend
ng serve

Mở http://localhost:4200, trang chào mừng của Angular hiện ra là dự án đã chạy.

Component đầu tiên

Mỗi phần giao diện là một component gồm ba thứ: class TypeScript, template HTML và style. Tạo thẻ bài viết bằng lệnh ng generate component post-card, rồi khai báo dữ liệu đầu vào:

@Component({
  selector: 'app-post-card',
  templateUrl: './post-card.component.html',
})
export class PostCardComponent {
  @Input() post!: Post;
}

Truyền dữ liệu giữa các component

Có ba cách hay dùng, theo thứ tự nên ưu tiên:

  1. @Input / @Output cho quan hệ cha con trực tiếp.
  2. Service dùng chung khi hai component không liên quan cần cùng một dữ liệu.
  3. State management (NgRx, Signals store) khi ứng dụng đủ lớn.

Gọi API từ backend

Đừng gọi HttpClient thẳng trong component. Đặt mọi lời gọi API trong service để component chỉ lo hiển thị:

  • Dễ viết test vì có thể thay service bằng bản giả.
  • Đổi địa chỉ API chỉ phải sửa một chỗ.
  • Interceptor gắn token, xử lý lỗi chung cho mọi request.
Component càng “ngốc” càng tốt: nhận dữ liệu, hiển thị, báo sự kiện lên trên. Mọi logic để ở service.

Một vài lỗi hay gặp

Lỗi CORS khi gọi API ở môi trường dev thường do backend chưa bật CORS cho localhost:4200. Lỗi NullInjectorError nghĩa là service chưa được cung cấp: thêm providedIn: 'root' vào decorator @Injectable.

Phần tiếp theo sẽ nói về routing có tham số và guard bảo vệ trang quản trị.
